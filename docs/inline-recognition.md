# Inline recognition and row calculations

Pending rows have a card in the right-side control rail: **Review math** at the top, a mini rendered preview beneath, then **Accept**. The expand icon opens a larger preview with horizontal and vertical scrolling; Shrink returns to the mini card. The rail itself scrolls when the cards need more vertical space. Accepted rows collapse to Compute. Ink and result positions do not move to make space.

Reading, review, accepted/compute, changed ink, failure and paused indicators describe transcription state, not mathematical correctness. Accept confirms the displayed transcription. Review math opens the existing correction sheet, where raw LaTeX, candidates and Clear transcription remain available. After acceptance, use the suggested calculation or Choose an operation → Review inputs → Compute → Insert result. Results and histories are scoped to the initiating row, presentations start fresh, and reuse is explicit. See [Calc 1 coverage](calc1-support.md) and [exact algebra](exact-algebra.md).

Only visible card/control rectangles consume touches. Geometry-derived hit rectangles follow side-rail scrolling; blank canvas still passes through to PencilKit. Expanded previews intercept their explicitly opened surface. Images are rendered serially, preserve full logical size for scrolling, and use a bounded decoded-image cache. Oversized or malformed typesetting leaves Review math available and disables inline acceptance. Acceptance checks the displayed ID, fingerprint, text and current ink through the existing persistence service.

Recognize after writing is a persisted optional setting, initially on. The existing provider is used, normally local TexTeller. A650ms trailing debounce schedules changed work; a preview can appear without opening a review menu. Ink edits invalidate affected acceptance, supersede pending work and preserve prior accepted revisions/results as history. Backgrounding cancels scheduling; returning active resumes changed work when enabled. Installed drawing callbacks use shared lifecycle State rather than retaining the scene's launch-time Environment value. Retry preserves accepted transcriptions and retries unaccepted work.

The scheduler prevents obsolete completion from clearing newer state. The coordinator checks cancellation, drawing fingerprints and math mode before applying responses. A model may finish its current runtime operation before cancellation is observed. Grouping heuristics, tokenizer/model weights and persisted schema were not changed by this UI/algebra batch.

ExpressionWorkflow/ExpressionReview/RecognitionIntegration tests cover safeguards. UI tests cover side placement, acceptance/correction, wide-expression expansion and scrolling, rail scroll hit targets, row result isolation and blank-page drawing; canvas regressions cover tools/undo. UI fixtures use a fixed recognizer and generated strokes, not a recognition-accuracy benchmark. Executed simulator and real-device evidence belongs to the release checkpoint.

Future correction UX: replace raw LaTeX with a structured visual math editor while keeping LaTeX as an advanced option. See [math-coverage-roadmap.md](math-coverage-roadmap.md).
