# folio-capstone-2027

Folio is a math editor for student-chosen steps, hints, and adaptive notation.
See [README.txt](README.txt) for setup, controls, verification status, and known limitations.

On an Apple Silicon Mac, build with `bash macos/build.sh` and open `build/Folio.app`.
Run offline checks with `bash macos/check.sh`. AI features use a separately installed
Ollama model; pretrained models are placeholders for future custom-model work.

The team requirements document remains in [docs](docs/).
